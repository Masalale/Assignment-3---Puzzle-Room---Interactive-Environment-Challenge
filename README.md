# Greenhouse at Night

> A single-room escape puzzle where the plants tell you what they need by sound.

Five dying pots, five minutes before they wilt, and one door that only opens when every one of them is alive again.

There's no instruction text in the room. Walk up to a pot you can't help yet and it plays the sound of the tool it wants: a water drop, or a light bulb click. Learn the room by ear, find what you heard, and get out.

## Controls

| Key | Action |
| :--- | :--- |
| `WASD` | Move |
| Mouse | Look |
| `E` / Left click | Interact · pick up |
| `Q` | Drop held tool |
| `Esc` | Pause menu |

## Requirements

- Unity `6000.3.23f1` (see `ProjectSettings/ProjectVersion.txt`)
- Unity Hub

## Getting started

```bash
git clone https://github.com/Masalale/Assignment-3---Puzzle-Room---Interactive-Environment-Challenge.git
```

Open the folder in Unity Hub → **Add** → select it, then open `Assets/Scenes/Greenhouse.unity` and press **Play**.
